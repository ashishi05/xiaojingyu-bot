# Emoji 猜成语

`/猜成语` 直接开局；481 道题，每轮随机 5 题，同轮不重复，尽量避开近期题。

- 每题四个 Emoji，按 2→3→4 个揭示；三阶段答对分别得 3/2/1 分。
- `/守株待兔` 等直接答题；每人每阶段一次。`/提示` 追加一个表情并重置阶段次数，四图出齐后再提示不会重置。
- `/揭秘` 在四图齐全后公布答案并立即换题；不自动提示，不超时揭晓。
- `/继续` 再开五题；`/换个猜` 打开玩法菜单。轮次结束和切换类型均保留整场累计积分。
- `/结束` 由本场开局者或管理员结算整场后清零；历史记录保留。`/积分` 查看各玩法通用的本场积分。
- 已知其他功能指令不会进入别名核验。陌生名称由模型判断；明确是不同成语或其他东西则判错，无法确认才不占次数。近义但不同的成语不能互认。
- 本会话与其他猜猜游戏互斥，普通聊天暂停；其他会话不受影响。

固定题面来源：https://www.guessemojis.com/chengyu ，2026-10-27 筛选 20 道公开的短 Emoji/成语配对。只保留题名及 Emoji，不复制站点释义或代码；难度是本地初筛，组合是意象或谐音借代，不保证单图精确。

题库：`data/plugins/idiom_guess/questions.json`。历史记录及近期题：`data/plugin_data/idiom_guess/scores.sqlite3`。整场总分共用 `data/plugin_data/guess_cup/scores.sqlite3`，不重新迁移或重置已有分数。
