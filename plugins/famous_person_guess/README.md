# Emoji 猜知名人物

入口 `/猜知名人物`；题库共 71 位人物。除猜角色选池外均直接开局；每轮随机 5 题，同局不重复，尽量避开近期 20 题。

## 指令与规则

- `/猜`、`/猜猜猜`、`/猜菜单` 显示已启用的游戏，查看菜单不会改变当前对局。
- 直接用 `/名字` 答题，例如 `/中国`，无需艾特；只接受完整名称或明确别名，普通聊天、图片、自发消息与只艾特别人的消息不作为答题。
- 每人每阶段一次。答对依次得 3／2／1 分；答错不扣分，但消耗当前阶段机会。重复作答只提醒，不重复结算。
- `/提示` 追加一个 Emoji，并重置所有人的阶段机会。第三个 Emoji 后再次提示只提醒“可揭秘或继续答题”，不重置次数。
- `/揭秘` 仅在三个 Emoji 全展示后可用；公布答案后立即换题，本题无人获得答对分。不自动提示、不超时揭晓，不发送文字线索和审题解释。
- `/结束` 仅本场开局者、QQ 群管理员或机器人管理员可用；结算整场后清零本场积分，公布当前题答案，列出全部得分者及游戏入口，不进入普通聊天或睡眠唤醒流程。零分参与者不单列。
- `/继续` 在结束后沿用上一局游戏和选池再开 5 题，七种玩法共用同一会话的本场积分，轮次结束和换玩法都不清零；仅 `/结束` 后的新一场从零累计。继续记录仅在本次运行内保留。
- `/猜知名人物 积分` 查看七种玩法共用的本场总积分，`/猜知名人物 帮助` 查看规则；`/积分` 在轮次之间也可查看，`/帮助` 在对局中可用。
- 游戏期间其他功能暂停；已知非游戏指令只提醒先结束，不进入别名检索，也不消耗机会。其他会话照常；七种游戏（含选池）在同一会话互斥。

## 题库与别名

仅核对同一真实人物身份，不接受亲属、相关人物或同职业替代。MJ 在本池指迈克尔·杰克逊，Michael Jordan 指迈克尔·乔丹。

题库保留 `clue_status` 与 `design_review`，部分线索属于设计建议，不标作逐条经用户确认。苏轼、金正恩、白求恩等指定组合保留。

题库位于 `data/plugins/famous_person_guess/questions.json`。本地名称完整匹配，统一大小写、空白及标点；陌生别名先由当前大模型根据候选名和本池名单独立判断；只有明确表示有把握、给出同一身份依据且只命中一个有效 ID 时才采用。模型明确识别为另一个实体时按错答处理并消耗阶段机会，积分不变。模型不确定或输出无效时，保留现有联网核验作为后备；仍无法确认就不占机会。不传当前题目、线索或聊天历史，也不自动修改题库；确认关系只缓存在本次运行内。未核实不占机会；不会根据当前题目猜测别名。

## 数据与验证范围

各玩法历史积分和近期题目仍保存在 `data/plugin_data/famous_person_guess/scores.sqlite3`；当前整场累计积分及开局者共享保存在 `data/plugin_data/guess_cup/scores.sqlite3`。七种玩法的题库和近期记录继续独立。重启结束当前轮，但保留本场累计积分；`/结束` 先结算再清零当前会话，历史分数不删除。首次部署会合并原有五种玩法分数作为本场初始总分，迁移仅执行一次。

复用 `emoji_guess/game.py` 的计分、对局锁和阶段检查。验证使用临时数据及模拟消息，不向真实 QQ 会话发送测试消息；未逐题联网核验或验证 QQ 客户端 Emoji 字形。
