# 本机桌面工具

管理员在QQ私聊中可以直接说“截一下现在的屏幕”“看看电脑上打开的窗口”“打开记事本，写一段文字”。任务需要时，机器人自行截图观察，每个动作后重新查看结果；只有明确要求查看截图时才发送图片到QQ。

快捷命令：
- `/桌面截图`：直接发当前桌面截图，不需要经过模型。
- `/桌面停止`：停止后续桌面动作并取消待确认操作；正在执行的输入会尽快中断并释放按键。截图仍可使用。
- `/桌面继续`：恢复，旧截图和待确认操作全部失效。
- `/桌面确认 六位确认码`：60秒内执行一次待确认动作；绑定原始发送者。

功能：多显示器截图、单击/双击/右击、拖动、滚动、Unicode文字和常用组合键。操作坐标以工具返回的截图为准，自动换算到物理桌面。截图最多保留30张，位于AstrBot临时目录的local_desktop子目录；AstrBot自己的工具图片缓存另由框架管理。

限制：需Windows交互桌面已解锁。不能控制UAC安全桌面或权限高于机器人进程的窗口。鼠标键盘会与本机用户共用。模型读图需要API实际支持图片；配置标记不等于已验证。

发送、删除、付款、最终提交和安全设置等操作由模型按目的标记risk后请求确认，确认流程在插件中执行。这是行为约定，不是系统级安全隔离；具备现有Shell权限的管理员仍可直接操作电脑。截图会发送到当前模型API供识别；明确要求发图时还会发送到QQ。

安装：将main.py、desktop.py、README.md放在AstrBot/data/plugins/local_desktop，重启AstrBot。无新增依赖。停用可在插件管理中禁用local_desktop。
