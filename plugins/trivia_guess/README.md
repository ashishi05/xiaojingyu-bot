# 猜假冷知识 · 扩充精选版

210条陈述：140条真实趣闻、70条假陈述，组成70组两真一假。
每条陈述在题组库中只出现一次；同组不出现相同主题，并混合至少两个类别。
选项顺序由现有游戏引擎随机打乱；本轮不重复陈述，最近玩过的题组继续按现有机制避让。
70组相当于14轮每轮5题的内容量，不保证跨会话或所有轮次都不重复。

选题围绕熟悉的动物、人体、食物、自然、太空和日用品；重点是反差与趣味，不以冷门名称和年份充数。
答对或揭秘后附三条简短解析。每条核对来源保存在 source-statements.json 和 questions.json。
假陈述的来源用于核对正确解释，不是给错误说法背书。

/猜假冷知识 开局，每轮5题；/1、/2、/3 答题，每人每题一次；答对3分，答错不扣分。
/揭秘 公布答案；/继续、/换个猜、/积分、/结束 沿用猜猜杯，累计积分保留。
