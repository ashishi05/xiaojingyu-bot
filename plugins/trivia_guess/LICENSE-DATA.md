# 冷知识题库许可与来源

`questions.json`、`source-statements.json` 中的题库按 [Creative Commons Attribution-ShareAlike 4.0 International（CC BY-SA 4.0）](https://creativecommons.org/licenses/by-sa/4.0/) 提供，与仓库代码的个人非商业许可分开。

部分保留陈述改编自 Open Trivia Database，导出来源为 [leakyhose/open-trivia-script-data](https://github.com/leakyhose/open-trivia-script-data)，对应记录保留 `source_question_id`。其余陈述由本项目根据所列机构资料重新撰写与组题；各陈述的核对来源记录在 JSON 文件中。假陈述的来源用于核对正确解释，不代表来源支持错误说法。

本项目改动包括中文改写、真假陈述编写、主题筛选、两真一假组题、答案解释及来源整理。上述共享许可仅针对题库文本，不扩展到来源网站文章、机构名称或图片。
