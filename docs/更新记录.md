# 更新记录

## 2026-10-28

本次将部署中的新增功能同步到公开版，保留公开版的相对路径、配置模板和账号占位符。不附带本机配置、聊天记录、历史积分、登录凭据或模型。

### 猜猜杯

- `/猜`、`/猜菜单`、`/猜猜猜`、`/换个猜` 查看已启用玩法。
- 猜角色：296 题，英雄联盟 173、无畏契约 30、星穹铁道 93，支持组合选池。
- 猜国家 42 题、猜游戏 55 题、猜知名人物 71 题、猜网络人物 55 题、猜成语 481 题。
- 猜假冷知识：210 条陈述组成 70 组两真一假，揭晓后附解释和核对来源。
- 每轮五题；`/继续` 沿用上一玩法和选池，换玩法保留本场积分；`/结束` 由开局者或管理员结算并清零本场。历史记录保留，不随源码包分发。
- 各会话对局隔离，同一会话玩法互斥；游戏期间暂停该会话普通聊天。成语分三阶段展示 2→3→4 个 Emoji，其余 Emoji 玩法按各自帮助逐步提示。
- 陌生别名先独立判断身份，无法确定时才用现有联网核验；不把当前题目和线索交给别名核验。

### 表情库

- `meme_data/` 包含 185 张原格式图片：日常选图池 181 张，待审核 4 张。
- 图片按自身标签组合命名，重名加序号；27 张补齐标签。
- 随包提供 `sticker_notes.json` 和图包的 `semantic_metadata.json`，同步文件名、路径和内容哈希。
- `meme_tag` 实际读取备注标签选图，并在备注文件变化后刷新；不是仅靠文件名猜标签。向量索引需在使用者本机另行配置，不随包分发。
- 图片的来源与权利说明见 [meme_data/README.md](../meme_data/README.md)。

### 现有功能更新

- 广告审核支持群号、进群链接、网址及确认的二维码作为审核线索；网址本身不直接触发处罚。指定群普通消息继续进入聊天，已处理广告消息由审核入口拦截。
- 管理员实际 @ 机器人时，可语义识别“去玩会儿、先休息”等退场意图；判定失败不擅自让机器人睡眠，之后 @ 可唤醒。
- 附件、引用、斜杠命令和明确 @ 机器人的消息绕过文本合并，保留原消息语境并及时处理。
- 当前消息明确带图时清除较旧图片缓存，避免下一次对话误带旧图。
- 文本清理保留代码和引文，跳过非模型结果。
- `start.ps1` 补充托盘启动，继续使用公开版配置读取方式。
- 开机启动文件夹只保留一个有效入口。停用的快捷方式移出启动文件夹备份，不在该文件夹内改成 `.disabled` 后继续存放。

### 更新与验证范围

先停止机器人、备份配置和插件数据，再替换源码并安装新增插件。七种猜猜插件以及功能菜单共用 `emoji_guess` 引擎，应一起安装或升级。`meme_data` 是部署数据快照，安装位置与替换注意事项见其说明。

源码验证使用模拟事件和临时数据库，不向真实 QQ 会话发消息，不对真实成员执行撤回或禁言。PowerShell 仅执行语法检查及明确无外部副作用的检查；涉及真实登录、计划任务、托盘窗口和系统桌面操作的流程不在发布检查中执行。

发布检查：18 组 Python 检查全部通过（其中 unittest 报告共 137 项，另有脚本断言检查）；21 个 PowerShell 文件语法检查通过。图片内容哈希、标签对应记录和公开文件的已知个人标识／凭据模式扫描通过。独立审查补充修复了审核异常吞消息和托盘路径空格问题。未安装 Ruff，未执行 Ruff 检查。
