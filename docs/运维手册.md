# 运维手册

面向已经部署好、需要日常开关和排错的人。首次安装看 [README](../README.md)。

## 1. 日常开关

| 操作 | 方式 |
|---|---|
| 启动 | 双击 `启动机器人.cmd` 或桌面「小鲸鱼」快捷方式 |
| 关闭 | 双击 `停止机器人.cmd`，或托盘右键「退出并关闭小鲸鱼」 |
| 重启 | 托盘右键「重启小鲸鱼」 |
| 打开管理页 | 托盘右键「打开管理页」（`http://127.0.0.1:6185`） |
| 开机自启 | 把 `autostart.vbs` 的快捷方式放进 `shell:startup` |

启动脚本会先探端口：6185（AstrBot）和 6099（NapCat）。已在运行就跳过，不会重复拉起。

## 2. 登录

- 首次启动会自动打开 NapCat 登录页，用手机 QQ 扫码
- 想免扫码：运行 `设置QQ自动登录.cmd`，密码用 DPAPI 加密存本机
- 遇到「账号使用受限」：按提示在手机 QQ 登录同一小号完成验证，再启动
- 换电脑后 `runtime\qq-password.dpapi` 解不开属正常，重新设置一次即可

## 3. 行为规则

- 私聊：直接说话即可；两个自用号共享上下文（`owner_session`）
- 群聊：默认要 @ 才会接话；连续对话有三分钟窗口；普通群友有频率限制
- 发「菜单」看当前功能
- 想让她闭嘴：管理员说「没你事儿了」；再 @ 一次唤醒（`sleep_mode`）
- 停止桌面操作：管理员私聊发 `/桌面停止`

## 4. 广告风控（ad_guard）

`ad_guard` 只对**一个指定群**生效，群号在 `plugins\ad_guard\main.py` 的 `GROUP` 常量里（默认 `100000001`，改成你的管理群）。

- 前提：消息里有连续 7 位以上数字、QQ 群进群链接，或确认过的二维码，才进入处理
- 招新、比赛、实验室、大创、志愿者等无商业利益活动放行
- 确认的兼职/推销：撤回 + 禁言 10 分钟，并私聊通知管理员
- 机器人必须在该群有管理员权限，才能实际撤回和禁言

## 5. 表情库

- 图片目录：`AstrBot\data\plugin_data\meme_manager\packs\official-001\memes\all`
- 备注与标签：`sticker_notes.json`
- 发图并说「这几个图加进表情库吧」即可收录；引用图片或指定最近五分钟的图片也支持
- `meme_tag` 负责按标签选图；`meme_admin` 负责批量收录
- 只改图片路径不改备注，可能找不到图

## 6. 人设与聊天记录

- 运行中的人格以 AstrBot 管理页里的设置为准；`persona\人设示例.md` 是源稿，不会自动同步
- 聊天记录在 `AstrBot\data\data_v4.db`，**不要提交到仓库**
- 长对话会压缩上下文，目前没有独立的长期记忆检索

## 7. 定时唤醒

托盘右键 →「定时唤醒设置…」：选日期/时间、仅一次或每天。电脑需处于睡眠且 Windows 用户已登录，锁屏可用，关机不能唤醒。

细节见 [maintenance/scheduled-wake/README.md](../maintenance/scheduled-wake/README.md)。

## 8. 日志与排错

| 日志 | 位置 |
|---|---|
| 启动器 | `logs\launcher.log` |
| AstrBot 输出 | `logs\astrbot.out.log` / `logs\astrbot.err.log` |
| NapCat 输出 | `logs\napcat.out.log` / `logs\napcat.err.log` |
| 定时唤醒 | `logs\wake.log` |

常见问题：

| 现象 | 处理 |
|---|---|
| 点启动没反应 | 看 `logs\launcher.log` 最后几行 |
| 6185/6099 被占 | `Get-NetTCPConnection -LocalPort 6185,6099` 找到进程再决定 |
| 服务起了但 QQ 不在线 | 托盘 → 打开管理页 → 扫码/密码登录 |
| 插件不生效 | 确认路径是 `AstrBot\data\plugins\<插件名>\main.py`，然后重启 AstrBot |
| 模型不回复 | 检查 AstrBot provider 配置与 API Key；查看 `astrbot.err.log` |
| 表情发不出 | 检查 `meme_manager` 是否安装、图片目录与 `sticker_notes.json` 是否对应 |

## 9. 备份与升级

**要备份的**：

- `AstrBot\data\`（含数据库、插件数据、人格）
- `config.json`、`runtime\qq-password.dpapi`（可选，换机重设）
- 自己改过的 `plugins\`

**不用备份的**：`AstrBot\.venv`、`NapCat\`、`logs\`。

升级 AstrBot：先备份 `data\`，再替换程序目录；插件一般兼容 4.x，大版本升级后逐个确认。

## 10. 卸载

1. 托盘退出，运行 `停止机器人.cmd`
2. 删除 `shell:startup` 里的自启快捷方式
3. 删除整个部署目录即可；QQ 登录态在 `NapCat\` 里，随目录一起删除
