# 小鲸鱼控制中心

可选的 Windows 启动器升级包。仓库原版入口保持不变；运行根目录的 `安装控制中心.cmd` 后，才将本机入口切换到控制中心。不包含账号、密码、聊天数据或第三方运行环境。

## 安装

1. 先按仓库说明安装 AstrBot 4.29.3+，配置根目录 `config.json`；官方 QQ 与 NapCat 连接按需配置。每种类型目前支持一个连接实例。
2. 首次安装前退出旧托盘、停止原机器人，避免两套托盘同时接管服务。备份 AstrBot 配置和插件数据。
3. 在 AstrBot 虚拟环境安装依赖：`AstrBot\.venv\Scripts\python.exe -m pip install psutil requests`。自定义路径请使用自己的 Python 路径。
4. 双击 `安装控制中心.cmd`。安装器备份旧入口、安装状态插件，在本机询问 AstrBot 管理面板用户名和密码。密码隐藏输入，使用 Windows DPAPI 加密保存，不写入源码或命令参数。
5. 启动 AstrBot 后，在插件管理中重载 `launcher_monitor`，再双击 `启动机器人.cmd`。如需重新填写面板凭据，使用配置的 Python 执行根目录 `setup_credentials.py`。

机器人核心、NapCat 及 Python 应放在部署目录内。控制中心只关闭部署目录内的相关进程；外部 Python 或服务目录的关闭操作会被拒绝。路径和端口读取 `config.json`。这不是独立 EXE，不捆绑 AstrBot、NapCat、模型或本地凭据。

## 管理

- **总览**：两个机器人独立启动、关闭、重启；状态灯、连接时长、任务摘要、最近动态。
- **任务与定时**：等待、思考、工具调用和回复发送阶段；查看定时任务及每日赛程，暂停或恢复所选任务。悬停定时任务可看备注。关闭服务时不能修改定时。
- **启动设置**：Windows 登录自启、分别选择自动启动的连接、只显示托盘、可选自动重连。偏好单独保存，退出不会清掉下次启动选择。
- **运行记录**：最近启停和定时修改结果、详细日志入口。

绿灯表示当前检查就绪；黄灯表示正在处理、连接或等待登录；红灯表示未启动或连接异常。官方连接检查已建立的 SDK 会话与打开的 WebSocket，自用 QQ 还检查 NapCat 登录状态。连接时长从本次首次确认就绪开始计时；重载状态插件后官方计时重新开始。

最小化和关闭窗口都收进托盘。**退出启动器会关闭全部机器人**。启动中请求停止或退出，会等待当前步骤收尾。普通模型任务不提供强制取消；未收到结束回报时提示检查日志。重连默认关闭，开启后每隔至少 60 秒尝试，连续失败最多 3 次。

## 恢复旧入口

退出控制中心，在安装输出的 `backups/control-center-时间戳/` 中取回原 `launcher.ps1` 和 `tray.ps1`。如曾开启自启，恢复后检查启动文件夹快捷方式。状态插件可在 AstrBot 中禁用。不要删除自己的运行数据、配置和聊天数据库。

## 验证范围

开发机已检查连接判断、任务阶段、偏好独立保存和实际总览排版。公开包另做路径、凭据边界和脚本语法检查。未在全新 Windows 环境完成真实 QQ 登录、重启电脑后的自启和退出全部流程。任务采集覆盖模型请求，直接发送消息的插件可能不经过这些阶段；请在自己的测试会话确认。
