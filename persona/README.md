# 人设使用与修改

`人设示例.md` 是一份写给 AstrBot 的「鲸鱼娘」系统提示词，覆盖私聊亲近、群聊克制、管理员与普通群友分级、工具权限边界。

## 导入

1. 打开 AstrBot 管理页 → 人格 / Persona
2. 新建人格，把 `人设示例.md` **去掉开头注释后**整段粘贴
3. 选择该人格，保存并重载

> 文件开头有一段 `<!-- ... -->` 注释，是给人看的修改提示。粘贴进机器人前可以整段删掉，免得占 token。

## 改称呼

默认称呼是「老大」。想改：

- **推荐**：在 AstrBot 人格设置里直接编辑，全文替换「老大」为你想要的称呼
- 或改本文件后重新粘贴

「老大」出现在这些位置（改的时候顺手检查一遍）：

| 段落 | 作用 |
|---|---|
| 一、身份与关系 | 定义谁是管理员、怎么称呼 |
| 群聊身份区分 | 群里对管理员仍叫老大，对群友不叫 |
| 表达与分条 | 私聊语气、撒娇尺度 |
| 群聊发言规则 | 什么时候接话、什么时候潜水 |

只想换叫法、不想动结构：全文替换即可。想换语气：改「表达基线」和「私聊分条」两段最有效。

## 占位号

| 占位符 | 含义 |
|---|---|
| `10001` / `10002` | 管理员 QQ（可以是同一个人两个号） |
| `10003` | 机器人 QQ |
| `10004` | 其它机器人账号（`group_bot_note` 用） |
| `200000001` / `200000002` | 群号 |

**公开仓库里不要出现真实号码。** 改完记得同步 `plugins` 里的同名常量，否则权限判断会对不上。

## 建议保留的约束

这几条不是装饰，删了容易出事：

- 普通群友只能用联网搜索，不能操作本机、读写文件
- 不对外复述私聊内容、不晒路径/密钥/账号
- 对亲密或恋爱话术明确拒绝，不随熟悉程度升级关系
- 涉及未成年人的内容一律拒绝
