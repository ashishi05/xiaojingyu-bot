# 定时唤醒（scheduled-wake）

让电脑在指定时间**从睡眠中醒来**，并自动保证小鲸鱼 QQ 机器人在线。

> 只能从**睡眠**唤醒。Windows 无法从**关机**状态自行开机（那是 BIOS/UEFI 的 RTC 定时开机或智能插座的活）。

## 托盘界面

右键小鲸鱼托盘 → **定时唤醒设置…**。可启用/停用，选择“仅一次”或“每天”，设置日期、时间并查看下次执行时间。打开窗口只读现有安排，点击“保存”才应用。

具体安排以设置窗口中的“重复”和“下次唤醒”为准。任务名仍是 `小鲸鱼-定时唤醒`，不会另建第二个任务。

本机已确认支持 S3 睡眠，当前电源方案的唤醒计时器已启用。计划任务使用当前 Windows 登录会话，所以锁屏可以，注销后不能保证启动本机 QQ。QQ 如触发安全验证，仍需手机确认。唤醒后保持系统运行 14 小时，显示器仍可自动关闭；保持运行进程有单实例保护。

唤醒后先等网络恢复。机器人和 QQ 在线则继续运行；未启动或掉线时调用现有 `launcher.ps1 -Quiet`，不通过先关停整个机器人来恢复，最后在 `logs/wake.log` 记录实际 QQ 状态。

验证通过：PowerShell 5.1 的一次/每天触发器、过去和非法时间校验、托盘资源、唤醒参数、窗口排版。没有自动让电脑睡眠，实际睡眠唤醒尚待使用时观察。

## 文件

| 文件 | 作用 |
|---|---|
| `wake_settings.ps1` | 托盘打开的定时唤醒设置窗口 |
| `setup-task.ps1` | 注册 / 查看 / 删除 Windows 计划任务 |
| `wake_bot.ps1` | 唤醒后自检：等网络 → 查端口 → 查 QQ → 掉线时复用一键启动尝试恢复登录 → 启动保持唤醒 |
| `keep_awake.ps1` | 保持系统 14 小时不休眠（显示器照常可关） |

日志：`<部署目录>\logs\wake.log`

## 用法

```powershell
# 每天 10:00 唤醒
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<部署目录>\maintenance\scheduled-wake\setup-task.ps1" -Daily -Time "10:00"

# 指定某天 10:00 唤醒一次（24 小时制）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<部署目录>\maintenance\scheduled-wake\setup-task.ps1" -Date "2026-10-27" -Time "10:00"

# 只看状态
... setup-task.ps1 -Status

# 删除任务
... setup-task.ps1 -Remove
```

参数：

| 参数 | 说明 |
|---|---|
| `-Time "10:00"` | 触发时刻，24 小时制，默认 `10:00` |
| `-Date "yyyy-MM-dd"` | 只唤醒一次，配合 `-Time`；省略则表示今天/明天最近的一次 |
| `-Daily` | 每天触发；与 `-Date` 互斥 |
| `-Status` / `-Remove` | 查看 / 删除任务 |

## 依赖与限制

- 电源设置里的「允许使用唤醒定时器」必须开启（当前 `RTCWAKE = 1`，已确认）。
- 任务以当前用户、交互式运行，需用户保持登录（锁屏可以）。
- 白天没有操作时，`keep_awake.ps1` 会阻止系统再次睡眠；14 小时后自动释放。
- **QQ 掉线到需要扫码/安全验证时，脚本无法代替人工确认**，这是唯一不能全自动的环节。
- PowerShell 5.1 读取无 BOM 的 UTF-8 会把中文注释解析成乱码并报语法错，所以这三个 `.ps1` 必须保存为 **UTF-8 with BOM**。改动后请保持 BOM。

## 给插件/Codex 的集成点

- 入口脚本：`setup-task.ps1`，成功时输出中文摘要（可直接回给用户），失败时抛出异常。
- 建议做成管理员命令，例如「每天10点叫醒我」「明天9点半唤醒」「取消唤醒」「唤醒状态」：
  1. 解析自然语言 → `-Daily`/`-Date`/`-Time`
  2. 调用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "...\setup-task.ps1" ...`
  3. 把 stdout 原样返回给管理员
- 需要读取执行结果时，看 `logs/wake.log`（每次唤醒都会写「唤醒任务触发」和结果）。
- 计划任务名固定为 `小鲸鱼-定时唤醒`，插件只需记住这个名字即可查询/删除。

保存反馈：点击后立即显示“保存中”和持续进度条；完成后显示核实过的下次执行时间，失败时显示原因并保留当前输入供重试。选项更改未保存时会明确提示。
