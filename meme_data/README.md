# 表情库与调用标签

2026-10-28 快照，共 185 张：`memes/all` 中 181 张供日常选图，`memes/needs_review` 中 4 张保留待审核。

文件名按每张图片自己的标签组合命名。`sticker_notes.json` 的 `tags` 字段是 `meme_tag` 的实际选图依据；图包里的 `semantic_metadata.json` 用于语义管理。两份记录均已随图片同步。不要只复制图片而遗漏标签。

## 安装

先按主说明安装第三方 `meme_manager`。本目录的**内容**对应 AstrBot 部署中的：

`AstrBot/data/plugin_data/meme_manager/`

全新部署可将本目录的 `packs/` 和 `sticker_notes.json` 复制到该位置。安装后重载 `meme_tag` 或重新启动机器人。使用当前公开版时，备注变化也会在下一次选图时刷新。

已有图库的更新：先停止机器人并完整备份。将旧 `packs/official-001` 整个移出活动数据目录保存，再复制本包同名目录，避免旧文件名的图片残留造成重复。已有其他图包或自定义备注时，先合并 `sticker_notes.json`，不要直接覆盖。不要改动其他图包、配置、历史积分或聊天数据库。

向量索引不随包提供，需要在本机配置后重建。4 张待审核图片不自动加入日常选图池。后续新增表情不会自动套用本次批量改名，需要同时维护图片名和对应标签记录。
